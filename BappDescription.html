This Burp Suite Extension allows you to integrate Burp Suite into the Faction assessment collaboration framework. It supports both OWASP Faction (Faction 2.x, the current release) and the original Faction (1.x); choose the version your server runs in the extension's Config tab.

Faction allows you to:

  1. Automate Vulnerability Reports
  2. Collaborate with other pen-testers
  3. Track Vulnerabilties to Closure

Usage

  1. In the Faction tab's Config sub-tab, pick your Faction version, enter the server URL and API key, then Save and Test Connection.
  2. Select the request or response you want to include in your report, right click and use the extension-generated context menu item to "Add new finding".
  3. Search for existing Vulnerability Templates and select only the part you want to include in the report.
  4. Get full details of findings in burp that you and other assessors have discovered. You can even replay the request from the UI.
  5. Finalize the report in the Faction Web Interface.
